# Citiz à La Réunion · rapport de l'équipe Super Transport

Copie publiée du rapport centralisé du Hackathon Microsoft × Citiz (21 octobre 2026),
pour le consulter sans cloner le dépôt de travail ni installer le pipeline.

- `index.html` : le rapport (une seule page, données ouvertes agrégées embarquées ;
  une connexion Internet est nécessaire pour Leaflet et le fond OpenStreetMap).
- `map/` : les cartes d'origine de l'équipe.

Le code, les données et la documentation restent dans le dépôt de l'équipe
(privé). Cette copie est mise à jour à la main depuis `deliverables/rapport/`.
